# Ali Alyossef — Portfolio

A single-page portfolio site built with plain HTML, CSS, and JavaScript — no build step required.

## Structure
```
index.html
css/style.css
js/script.js
images/          (project screenshots)
```

## Deploying to GitHub Pages

1. Create a new repository on GitHub (e.g. `portfolio` or `ali-alyossef.github.io`).
2. Upload all these files to the repo, keeping the folder structure as-is.
3. Go to the repo's **Settings → Pages**.
4. Under **Source**, select the `main` branch and `/ (root)` folder, then save.
5. GitHub will give you a live URL (usually `https://yourusername.github.io/repo-name/`) within a minute or two.

## Things to customize later
- Swap the placeholder project URLs in the browser address bar (`shop.co`, `corporation.com`, `shopcart.com`) for real live links if the sites are public, or remove the URL bar text if not.
- Add your WhatsApp link in `index.html` — search for `WhatsApp — coming soon` and replace it with a link like `https://wa.me/<yourNumber>`.
- Replace the screenshots in `/images` any time you want to feature newer work.
